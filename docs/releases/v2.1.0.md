新增 IPv6 原生转发和 IPv4/IPv6 内核跨族转发，保留原 IPv4→IPv4 功能。

- 支持 IPv6→IPv6、IPv6→IPv4、IPv4→IPv6 的 TCP/UDP、单端口和等长端口段，以及两族复用本地端口。
- 同族使用 nft，跨族使用专用 namespace 中的 Jool 内核转换，无常驻用户态中继。
- 新增 `install-jool` / `check-jool` 和菜单依赖管理，处理 Debian 11/12/13 的匹配 headers、旧 ABI 退役及内核类型指引。
- 扩展跨组件回滚、独立 systemd 保护和启动恢复，保持 IPv6 RA，兼容 Rocky SELinux Enforcing。
- 兼容旧三字段配置，新增显式入口地址族；支持只读规则与完整部署计划预览。

升级与使用：

- 跨族转发需要匹配当前内核的 Jool 4.1.15 或更新的 4.1 系列工具与模块、两族路由及 namespace/veth 权限；首次运行 `sudo bash nft.sh install-jool`。
- 白名单按地址族匹配。IPv6 客户端需要添加实际客户端 IPv6 或自己控制的网段。
- 当前实现中，后端看到 VPS 出站地址。重建转换实例可能中断既有连接。
- 旧配置可继续使用；降级到 v2.0.0 前需撤销跨族资源并恢复旧格式配置。

验证包含 294 项 Linux 单元、34 项依赖测试、84 项内核转发、38 项同号端口、8 项 systemd 内核回滚，以及 netns / systemd / Docker-WireGuard 回归。Debian 11/12/13 的六组模块构建与规则解析通过；Debian 双栈 VPS 与 Rocky 独立内核完成真实重启。尚未承诺吞吐或大规模会话容量，Debian 11 的构建检查不等同于 5.10 内核数据路径验收。

附件为独立运行脚本 `nft.sh` 和校验文件 `SHA256SUMS`。下载后运行 `sha256sum -c SHA256SUMS` 校验。
